cloudflared.exe (Windows amd64) — conector Cloudflare Tunnel do Unitec ERP.

Gerado automaticamente ao criar o pacote de update:
  .\scripts\criar-pacote-update.ps1

Ou baixe manualmente:
  https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe

Salve como: resources\cloudflared\cloudflared.exe

No cliente, o ERP copia para C:\ProgramData\Unitec\cloudflared\ ao Ativar / Atualizar status.
Não use "Install connector" do Zero Trust — o UnitecErpServer sobe o processo.
